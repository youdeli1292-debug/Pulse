⚡

Fast Execution

Ctrl+Enter sends the Lua buffer to the interpreter and returns the result, the exit code and the elapsed time. Output lands in a floating panel over the editor, and a long script can be cancelled at any moment.

  • lua / luajit auto-detection
  • exit code + duration report
  • floating output panel
◈

Custom UI

A fully frameless 800 × 500 neon-violet shell drawn by hand: custom title bar, drag region, window controls, tabs, gutter, scanline overlay and a compact two-pane layout with no empty space.

  • frameless window + custom chrome
  • editor + Script Hub side by side
  • slim status bar at the bottom
⌨

Monaco Editor Integration

The same editor engine that powers VS Code, permanently locked to Lua: highlighting, bracket colourisation, suggestions, multi-cursor and a custom pulse-cyber theme — bundled offline inside the app.

  • Lua syntax, hardcoded
  • custom neon theme & ligatures
  • built-in fallback editor
⛓

Attach & Status

Press Attach and Pulse looks for the Roblox process, binds to it and flips the status bar to a green “Status: Attached”. The badge turns red the moment the game closes.

  • automatic Roblox process lookup
  • live PID watcher
  • green / red status badge
❯❯

Script Hub

A built-in catalogue of ready-to-run Lua scripts — Fly, AimBot, ESP, SpeedHack, Infinite Yield, Noclip, Anti-AFK. One click loads the source straight into the editor, and the search box filters the list instantly.

  • 7 scripts out of the box
  • one click, straight into the editor
  • instant search + hideable panel
🛡

Safe by Design

The renderer runs with context isolation and without Node integration. Every privileged action travels through an explicit IPC channel, and interpreters are launched without a shell, so nothing can be injected into your system.

  • contextIsolation + preload bridge
  • no shell string interpolation
  • whitelisted system utilities

Installation

Three steps, about a minute, nothing to configure.

  1. 1

    Download the portable build

    Grab Pulse-1.0.0-x64-portable.exe from the releases page. It is a single self-contained file — Pulse leaves no traces in the registry.

  2. 2

    Put it anywhere and run it

    Copy the .exe to a folder you own (Desktop, D:\Tools, a USB stick) and double-click it. Windows SmartScreen may ask for confirmation on the very first launch — press More info → Run anyway.

  3. 3

    Run your first script

    Press Ctrl+Enter to execute the Lua buffer, Ctrl+H to open the Script Hub and pick a script, and Ctrl+B to attach to the Roblox process.

Node.js 18+ is required. Clone the repository and run:

cd Pulse
npm install
npm run dist

The finished portable executable appears in dist/.

FAQ

Do I need admin rights to run Pulse?

No. The portable build requests the normal user level and writes only inside your user profile (%APPDATA%\pulse\workspace).

Which interpreter runs the scripts?

Pulse looks for lua / luajit on your system at startup and shows the result in the sidebar. Without an interpreter you can still edit and load scripts — execution simply reports “Lua interpreter not found”.

Does Pulse need an internet connection?

No. The Monaco bundle, fonts and theme are packaged inside the executable; nothing is loaded from a CDN at runtime.

How does Attach work?

Pulse scans the process list (tasklist on Windows, ps on Unix) for RobloxPlayer / RobloxStudio and binds to the PID it finds. The status bar switches between “Status: Not Attached” (red) and “Status: Attached” (green) and follows the process until it exits.

Monaco did not load — now what?

Pulse falls back to its own editor with line numbers and Lua syntax highlighting, so the app stays fully usable.

What is inside the Script Hub?

Seven commented Lua templates built only on the documented Roblox API — movement, visuals and an admin command bar. They are meant for your own places and private servers: no network calls, no data collection, every effect is reversible.
